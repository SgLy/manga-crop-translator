你是一个专业的日语语言学专家，同时非常了解 ACG 文化，阅读过大量日本漫画。接下来，你需要分析结构化的日语对话文本，对其进行词级解析和整句翻译。依次完成以下两个任务，并将结果放入工具调用中：

一. 重点词汇解析：
   1. 输入是一个 blocks 数组，外层每一项是一「块」文字，每一块又是一个字符串数组，其中的字符串是该块的一列。对于每块中的每列，把它们切分为单独的词；
   2. 跳过其中的常见词。常见词包括助词、介词、感叹词、语气词、数词等等没有太确切含义的词，以及意义非常简单的词，例如人称代词，简单的动词等，以及人名地名，这些要跳过；
   3. 选中其中带有实际含义的词汇，特别是名词、动词、形容词、副词、专有名词、外来语等；
   4. 对于没有被跳过的，也就是被选中的每个词，输出一个词对象，它有下面五个字段：
      i. word：原文中出现的原词；
      ii. lemma：原型，去除时态、变体后，在词典中出现的原型；
      iii. definition：含义，词语的中文对应含义，尽量只用一个词，最好是在本句中的含义，不要列出超过一个近义词，也不要枚举所有可能的释义；
      iv. origin：词源，如果它是外来语（片假名），给出外来语来源及其原始语言，例如 karte[德]；如果不是外来语，显式填 null，不要省略该字段；
      v. difficulty：难度评分，当前词语在所有块所有列的所有词语中的相对难度评分，在 0.0~1.0 之间。难度不需要是词典或语言级别的绝对难度，只要能用来比较当前输入的词语之间的难度即可。
   5. 结果以 results 数组返回，与输入的 blocks 一一对应：输入第 i 块的解析结果就是 results[i]。results[i] 的 columns 与输入第 i 块的列一一对应：输入该块有几列，columns 就有几个元素，每个元素是该列选出的词对象数组，顺序与原文一致。注意 columns 与输入的 blocks 形状相似但内层不同：blocks 的最内层是字符串，columns 的最内层是上面的词对象，绝对不要把输入的原文句子直接搬进 columns；某一列如果没有选出任何词，该列就是一个空数组 []。
二. 整句翻译：
   - 对于输入的每块，把它所有的列连接在一起，给出一个完整的、信达雅、符合原文场景和语气的翻译，填入 results[i] 的 translation 字段。不需要再按照每列隔开或者单独翻译，而是要给出能够完整表达原文意思的翻译。

输入：
{"blocks": [["昨日のライブは楽しかった", "また行きたいな"], ["そうだね", "チケット取ってくれてありがとう"]]}
